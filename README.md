## ✦ Overview

**Heartopia WIKIOS** is a specialized dashboard providing real-time data to help you stay ahead. Designed with a sleek, data-driven interface, it focuses on server-wide events, environmental cycles, and critical reset times, backed by a powerful administrative content management system.

## ✦ Features

### 🕒 Precision Server Time
* **Multi-Region Support** — Seamlessly sync with **SEA, TW/HK/MO, ASIA, GLOBAL, and AMERICA** servers.
* **Dynamic Resets** — Automatically track daily reset cycles based on server-specific UTC offsets.
* **Real-Time Accuracy** — Live clock calibrated exactly to your selected region.

### 🌦️ Environmental Forecast & Automation
* **Condition Monitoring** — Stay updated on current and upcoming weather patterns.
* **Atmospheric Events** — Track specialized occurrences like *Rainbows, Meteor Showers, and Petal Rain*.
* **Time-Block Logic** — Forecasts are divided into precise daily slots (Morning, Afternoon, Night).
* **Automated Discord Notifier** — Integrates directly with Discord Webhooks to broadcast:
  * **Daily Resets (6 AM)**: Morning summaries with the day's full forecast.
  * **Early Warnings**: Notifies users exactly when rare weather is approaching.
  * **Live Alerts**: Triggers real-time notifications when major weather patterns begin.

### 📍 Doris Location Tracker
* **Smart Tracking** — Real-time updates on Doris's current whereabouts.
* **Specialized Spotting** — Unique locations tied to specific rare weather events are automatically prioritized.
* **Region-Synced** — Data reflects the exact time and cycle of your chosen server region.

### 🎁 Redeem Codes Manager
* **Automated Parser** — Easily paste raw text from Discord community channels and the Manager will automatically parse and detect codes, rewards, and expiration dates.
* **Expiration Tracking** — Expiration badges automatically mark codes as invalid based on real-world time.
* **Bulk Management** — Full capability to select multiple codes and delete or manage them.
* **1-Click Copy** — Seamlessly copy active codes.

### 🛠️ Developer Admin Tools & CMS
* **Workbench** — Dynamically build out new Wiki categories, tables, and settings.
* **Card Customization** — Tailor the specific look, feel, layout, grids, and filters of each particular category.
* **Database SQL Tools** — Get setup fast by copying standard Supabase PostgreSQL tables directly from the dashboard UI. Security through RLS (Row Level Security).
