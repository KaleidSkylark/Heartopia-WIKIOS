## 🌟 Overview

**Heartopia WIKIOS** is a specialized dashboard providing real-time data to help you stay ahead. It focuses on server-wide events, environmental cycles, and critical reset times to streamline your experience through a sleek, data-driven interface.

### 🚀 Key Features

#### 🕒 Precision Server Time
- **Multi-Region Support**: Sync with **SEA, Global, Asia, and TW/HK/MO** servers.
- **Dynamic Resets**: Automatically tracks daily reset cycles based on server-specific UTC offsets.
- **Real-Time Accuracy**: Live clock calibrated to your selected region.

#### 🌦️ Environmental Forecast
- **Condition Monitoring**: Stay updated on current and upcoming weather patterns.
- **Atmospheric Events**: Track specialized occurrences like **Rainbows, Meteor Showers, and Petal Rain**.
- **Time-Block Logic**: Forecasts are divided into precise daily slots (Morning, Afternoon, Night).

#### 📍 Doris Location Tracker
- **Smart Tracking**: Real-time updates on Doris's current location.
- **Specialized Spotting**: Unique locations tied to specific weather events are automatically prioritized.
- **Region-Synced**: Data reflects the current time and cycle of your chosen server region.
